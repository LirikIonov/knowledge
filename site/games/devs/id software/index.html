    id Software¶

    Разрезанная MkDocs-версия большой базы по истории id Software: пункты 1–79. Исходный содержательный текст сохранён без сокращений; материал разделён по историческим эпохам, чтобы отдельные страницы были удобнее для MkDocs, навигации и дальнейшего редактирования.

    Главный вопрос базы:

    Как маленькая компания, построенная вокруг нескольких совершенно несовместимых сильных личностей, пережила уход почти всех создателей, продажу корпорации и смену нескольких поколений — и всё равно осталась узнаваемой как id Software?
