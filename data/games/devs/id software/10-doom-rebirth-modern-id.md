## 58. Отмена старого Doom 4 и рождение Doom 2016 { #p058 }

Важно не представлять reboot как одномоментное решение. На деле это rolling reset, но где-то в 2012–начале 2013 происходит decisive shift.

### Новая команда формулирует вопрос

```
ЧТО ТАКОЕ
DOOM?
```

И начинает разбирать Doom, Doom II и Doom 3, чтобы найти design DNA, а не сделать literal remake.

Постепенно всё сжимается примерно до:

```
GUNS
DEMONS
MOVEMENT
```

И соединяющего принципа:

### PUSH-FORWARD COMBAT

Игрок должен решать проблему через движение **к угрозе**, а не от неё.

### История Glory Kill

Одним из переломов становится эксперимент animation team. Берутся старые assets Doom 4 и пробуются быстрые brutal executions прямо в gameplay.

И внезапно возникает идея:

```
ENEMY
не просто
умирает
↓
может стать
RESOURCE
```

Glory Kill превращается из cosmetic finisher в системную механику:

```
DAMAGE
↓
STAGGER
↓
CLOSE DISTANCE
↓
GLORY KILL
↓
HEALTH
↓
CONTINUE
```

Animation одновременно становится spectacle, healing mechanic, positioning incentive и aggression teaching tool.

### Поэтому нет regenerating health

Если healing происходит через «подожди за стеной», player учится пассивности.

Новая Doom хочет:

```
НУЖЕН HEALTH?
↓
ИДИ
В ДРАКУ
```

Chainsaw позднее становится ammo generator. Enemy теперь одновременно threat и resource.

### Movement становится defense

Вместо cover — постоянное движение.

```
НЕ СТОЙ
```

Player живёт потому, что перемещается.

### Hugo Martin

Он становится full-time creative leadership примерно в период reboot. Его Hollywood/concept background используется для visual clarity, silhouettes, staging, readable spectacle и strong player fantasy, а не для пассивного кино.

### Combat chess

Враги проектируются как tactical roles, weapons — как tools. Каждый demon должен заставлять думать и двигаться.

### Arena design

Не cover spaces, а movement networks: height, routes, jump opportunities, flank paths, resources, enemy pressure.

### Ностальгия используется не буквально

Не:

```
СКОПИРУЕМ
1993 geometry
```

А:

```
КАКОЕ
ЭМОЦИОНАЛЬНОЕ
ОЩУЩЕНИЕ
ДАВАЛ
СТАРЫЙ DOOM?
↓
СОЗДАДИМ
ЕГО
НОВЫМИ
СРЕДСТВАМИ
```

### Story перестаёт мешать

Lore есть. Samuel Hayden есть. UAC есть. Но player не обязан каждые пять минут ждать exposition.

Характер Slayer выражается через action. Player impatience и характер героя совпадают.

### Название

Проект постепенно перестаёт быть Doom 4 и становится просто DOOM.

Это statement: не очередная часть, а переопределение series.

QuakeCon 2014 — закрытый public reveal. E3 2015 — полноценный массовый show.

### Главная смена production philosophy

Старая:

```
TECH
→ GAME
```

Новая:

```
PLAYER FEEL
→ PROTOTYPE
→ SYSTEMS
→ TECHNOLOGY
→ CONTENT
```

Именно отсюда рождается современная id.

## 59. Doom 2016 — игра наконец становится важнее движка { #p059 }

13 мая 2016 выходит DOOM.

Самое исторически важное: люди обсуждают не renderer. Они обсуждают Glory Kills, movement, Super Shotgun, demons и combat.

### Push-forward combat — система, а не одна mechanic

```
MOVE
↓
SHOOT
↓
STAGGER
↓
GLORY KILL
↓
HEALTH
↓
KEEP MOVING
```

Параллельно:

```
CHAINSAW
↓
AMMO
```

Sustain встроен в aggression.

### Враги — tactical roles

Enemy должен считываться силуэтом, звуком, атакой и движением и быстро отвечать на вопрос:

```
ПОЧЕМУ
ЭТОТ DEMON
МЕНЯЕТ
МОЁ ПОВЕДЕНИЕ?
```

### Weapons — toolkit

Не линейная лестница upgrades, а набор инструментов. Weapon mods добавляют новые verbs, player постоянно переключается.

### Arena — сеть движения

Space существует для reposition, verticality, route selection, enemy management и resource management. Не для сидения за ящиком.

### Но структура тоже имеет минус

Постепенно campaign может считываться как:

```
коридор
↓
arena
↓
коридор
↓
arena
```

Высокий quality combat покупается ценой заметной encounter structure.

### Progression

Upgrades обычно расширяют possibilities — mods, runes, suit abilities — а не только дают +2% damage. Progression должна поддерживать mastery.

### Exploration сохраняет old Doom rhythm

Secrets, collectibles, optional spaces. Это пауза между arenas, но активная.

### Story — optional layer

Если тебе интересна UAC/lore — читай. Если нет — беги стрелять.

### Slayer — новый тип protagonist

Он одновременно avatar и character. Почти не разговаривает, но actions дают характер.

Lore поддерживает mechanics:

```
demons
боятся тебя
↓
gameplay
делает тебя
очень опасным
```

### Tone

Doom 3 была очень серьёзным horror. 2016 возвращает heavy-metal absurdity, UAC satire и comic-book aggression.

### Mick Gordon

Soundtrack не просто фон. Он реагирует на combat и усиливает rhythm. Audio становится частью feedback loop.

### id Tech 6 работает идеально именно потому, что player почти не думает о нём

```
PLAYER
ПОМНИТ
SUPER SHOTGUN

А НЕ
TEMPORAL
ANTI-ALIASING
```

Вот правильная hierarchy.

### Multiplayer и SnapMap

Multiplayer частично делает Certain Affinity. Есть SnapMap как попытка сохранить creator-DNA.

Но public reception почти полностью концентрируется на campaign.

Забавно: компания изобретателей deathmatch возвращается как single-player powerhouse.

### Doom 2016 — анти-RAGE

RAGE расширяла игру наружу: cars, crafting, hubs, racing.

Doom 2016 берёт shooting и углубляет внутрь.

Вот почему она цельнее.

### Это второе рождение id

Founders почти нет. Независимости нет. External engine business нет.

Но FEEL, TECH, PERFORMANCE, STRONG CORE и PLAYER CONTROL живы.

DOOM 2016 доказывает: id может пережить своих создателей.

## 60. id Tech 6 — новая инженерная id без Carmack { #p060 }

После ухода Carmack главный технический вопрос:

```
А id
ВООбще
МОЖЕТ
ДЕЛАТЬ
id-level
ENGINE
БЕЗ НЕГО?
```

Doom 2016 отвечает: да.

### Нет «нового Carmack»

Engineering leadership распределена между Robert Duffy, Tiago Sousa, Billy Khan, Jean Geffroy, Axel Gneiting и другими инженерами.

```
PERSON-CENTERED
ENGINEERING
↓
TEAM-CENTERED
ENGINEERING
```

### Robert Duffy

Это continuity. Он давно внутри id и проходит несколько engine generations. После Carmack именно такие ветераны позволяют technical culture не обнулиться.

### Tiago Sousa

Приходит из Crytek в 2014. Очень сильный graphics engineer.

Это ещё одна важная проверка institution: можно взять человека из другой сильной engineering school и встроить в id.

### id Tech 6 — не clean-sheet rewrite

Она глубоко развивается из id Tech 5, но architecture и priorities серьёзно перестраиваются.

### Самая важная фраза Duffy

> With DOOM we let the game drive the technology decisions from early on.

Вот разрыв с RAGE-era.

### 60 FPS — architecture target

Не marketing bullet.

Combat требует low latency, fast animation, precise aiming, responsive movement.

```
60 Hz
=
GAMEPLAY REQUIREMENT
```

### Dynamic resolution

Если scene тяжёлая, лучше немного снизить resolution, чем сломать frame pacing.

Image quality обслуживает feel, а не наоборот.

### Frames in flight и latency

Engine engineers думают не только о GPU utilization, но о том, как быстро input дойдёт до pixel.

Это старое Carmack-DNA, уже без Carmack.

### Early optimization

Performance — responsibility всех systems с начала production, а не «потом оптимизируем».

### Rendering

id Tech 6 использует dynamic lighting, PBR, HDR, hybrid forward/deferred ideas, temporal techniques, reflections, decals и modern shadowing.

Но нет одной marketing religion уровня Doom 3 \= dynamic shadows или RAGE \= MegaTexture.

Technology становится набором практических systems.

### PBR — ещё и production improvement

Он создаёт более предсказуемый art workflow. Artist быстрее понимает, как material будет выглядеть в разных условиях.

Engine теперь оптимизирует не только runtime, но и content creation.

### Virtual texturing не просто выкинули

Части lineage id Tech 5 сохраняются и эволюционируют. Но уменьшается dogmatism.

Если classic MegaTexture неудобна для storage/iteration/dynamic effects — system меняется.

### Engine специально делается под Doom

После отказа от external licensing больше не надо отвечать:

```
А МОЖНО
НА ЭТОМ
СДЕЛАТЬ
SKYRIM?
```

Неважно.

Вопрос:

```
МОЖНО ЛИ
СДЕЛАТЬ
DOOM
ЕЩЁ ЛУЧШЕ?
```

### Vulkan

DOOM изначально на PC выходит с OpenGL. Vulkan support добавляют 11 июля 2016 после релиза.

Это не rescue плохого PC port. PC version и так хорошая.

Vulkan даёт ниже CPU overhead, лучше multithreading, больше low-level control, async compute и потенциально выше framerate.

### Философия Vulkan у id

Правильный вопрос:

```
А PLAYER
ЧТО ПОЛУЧИТ?
```

Ответ:

```
HIGHER FPS
BETTER FEEL
```

API важен не как badge, а через gameplay benefit.

### Главный итог id Tech 6

Пережили performance, low latency, own engine, hardware expertise, technical ambition.

Изменилось главное:

```
renderer
больше
не диктует
game
```

Это и есть новая инженерная id.

## 61. Doom Eternal — id не повторяет Doom 2016, а делает систему жёстче { #p061 }

После Doom 2016 компания могла сделать самый безопасный sequel:

```
MORE DEMONS
MORE GUNS
MORE GLORY KILLS
SAME LOOP
```

Но modern id снова действует по старому хорошему принципу:

```
УСПЕШНАЯ FORMULA
≠
СВЯЩЕННАЯ FORMULA
```

### Что не устраивало команду в Doom 2016

Игрок к середине/второй половине campaign мог найти comfortable dominant strategy — условно Super Shotgun + Gauss + любимая рутина — и дальше долго не менять стиль.

Ceiling есть, но game недостаточно aggressively заставляет пользоваться всей системой.

### Eternal хочет постоянных решений

Отсюда Combat Chess, Speed Chess, Fantasy Combat Puzzle.

Идея:

```
POWER FANTASY
НЕ ДАЁТСЯ
БЕСПЛАТНО
↓
ТЫ
ЧУВСТВУЕШЬ
СЕБЯ SLAYER
ПОТОМУ ЧТО
НАУЧИЛСЯ
ИМ БЫТЬ
```

### Resource economy усиливается

```
Glory Kill
→ health

Chainsaw
→ ammo

Flame Belch
→ armor

Glory Kills
→ Blood Punch charge
```

Enemy — resource network.

Fodder demon — не мусор, а передвижной inventory.

### Ammo deliberately tighter

Если player может бесконечно стрелять одной пушкой, он не учится toolkit.

Поэтому Eternal постоянно подталкивает к switch.

Для одних это гениально. Для других — «дайте просто пострелять».

### Враги становятся задачами

Weak points — Arachnotron turret, Mancubus cannons и другие tactical appendages.

Разрушение части тела меняет enemy role. Visual damage влияет на систему.

### Возникает prescriptiveness

Чем сильнее id задаёт «этого лучше этим», тем меньше чистой sandbox-интерпретации.

Это главный trade-off Eternal: глубже, но более авторски контролируемо.

### Marauder — концентрат философии

Он заставляет читать дистанцию, ждать cue, таймить counter, менять priority.

Часть игроков его ненавидит, потому что Doom вдруг говорит «не беги вперёд прямо сейчас».

Команда защищает его как teaching enemy.

### Movement становится огромной системой

Double jump, dash, air control, monkey bars, wall climb, Meat Hook.

Если Slayer — более быстрая машина, арены должны стать больше, вертикальнее и сложнее.

### Meat Hook — великолепная systemic mechanic

Enemy одновременно:

```
TARGET
+
MOVEMENT ANCHOR
```

Combat и traversal сливаются.

### Platforming

Решает несколько задач: разбивает arena-corridor-arena, позволяет practice mobility без combat pressure, поддерживает kinetic rhythm.

Но может ощущаться как «Mario в Doom».

### Eternal сознательно становится gamey

Яркие pickups, 1-Ups, monkey bars. Mechanics должны мгновенно читаться. Это прямой отказ от cinematic naturalism.

### Lore становится значительно больше

Sentinels, Maykrs, Hell cosmology, Slayer mythology.

Для одних — расширение мира. Для других — 2016 была смешнее и загадочнее, Eternal слишком много объясняет.

### Eternal проектируется как долго живущий продукт

Year One Pass, The Ancient Gods, Master Levels, events, Battlemode, позднее Horde Mode.

Modern id строит почти live-service-scale infrastructure вокруг primarily single-player mastery game.

### The Ancient Gods

Part One — 20 октября 2020. Контент предполагает, что player уже знает system, и начинает давить high-level encounters.

Part Two — 18 марта 2021. Закрывает Slayer saga, добавляет variants и Sentinel Hammer.

DLC ещё сильнее увеличивают prescriptive side: combat местами почти превращается в real-time puzzle.

### Battlemode

```
1 Slayer
VS
2 player demons
```

Попытка перенести combat chess в multiplayer. Интересный concept, но культурным центром Eternal не становится.

### Invasion Mode

Планировался invasion других players в campaign. В 2021 отменён из-за production realities и смены priorities. Resources уходят в Horde Mode.

### Update 6.66

Horde Mode, Battlemode 2.0, Master Levels.

Именно system depth позволяет тем же demons в новых комбинациях создавать новый challenge.

### 2016 vs Eternal

```
2016:
чище
проще
мгновеннее
лучше flow
```

```
Eternal:
глубже
плотнее
выше skill ceiling
больше cognitive load
больше rules
```

### Главный исторический итог

Doom 2016 доказала, что post-Carmack id может сделать великую id game.

Eternal доказала, что она может **сама развивать новую философию**.

```
DOOM 2016
заставляет тебя
ПОЧУВСТВОВАТЬ
СЕБЯ SLAYER
```

```
DOOM ETERNAL
заставляет тебя
НАУЧИТЬСЯ
БЫТЬ SLAYER
```

## 62. Tim Willits покидает id Software { #p062 }

18 июля 2019 Tim Willits объявляет, что после QuakeCon покинет id. После 24 лет.

### Важная поправка

Иногда это описывают как «последний старый человек id ушёл».

Слишком грубо. Kevin Cloud, например, имеет ещё более раннюю lineage — приходит в 1992.

Точнее: Willits был последним очень публичным studio-level лидером с непрерывной карьерой ещё от Quake-era.

### Почему уход сильно отличается от Romero/Carmack

```
Romero:
CONFLICT
↓
COMPANY МЕНЯЕТСЯ
```

```
Carmack:
TECHNICAL CENTER УХОДИТ
↓
EXISTENTIAL QUESTION
```

```
Willits:
Я УХОЖУ
↓
CURRENT PROJECTS
В ХОРОШИХ РУКАХ
```

И studio просто продолжает.

Это огромный показатель maturity.

### RAGE 2 — символичный последний большой проект

Игра выходит в мае 2019. Основная production — Avalanche. id консультирует и co-develops shooter side.

Получается великолепная карьерная арка:

```
Quake
в одной комнате
в Texas
↓
RAGE 2
между Texas
и Stockholm
```

Willits прожил весь переход индустрии от tiny team до distributed AAA co-development.

### Doom Eternal уже не зависит от него

Когда Willits уходит, Eternal далеко в production. Но публичными Doom leaders уже давно являются Marty Stratton и Hugo Martin.

Leadership transition произошёл ещё до formal departure.

### Quake Champions тоже продолжает жить

И в 2022 формально выходит из Early Access в full release.

Ни один current project не рушится.

### Куда уходит Willits

В августе 2019 становится Chief Creative Officer Saber Interactive.

Его снова привлекает модель маленьких команд, быстрого iteration и разнообразия проектов внутри более крупной структуры.

### Историческая ирония

Willits всю карьеру помогает id пройти путь:

```
маленькая agile team
↓
большая AAA organization
```

А потом его снова привлекает small-team agility.

### Главное значение ухода

id теперь окончательно не `BUS FACTOR = 1`.

Hall ушёл — команда перестроилась.

Romero ушёл — культура изменилась.

Carmack ушёл — engineering пришлось доказывать себя.

Willits ушёл — практически ничего катастрофического не происходит.

Вот и есть institutional maturity.

### Quake identity после него

Willits лично прожил Quake, Quake II, Quake III, Quake 4-era, Quake Live и Quake Champions.

Когда такие люди уходят, Quake identity теперь хранится не в живой персональной памяти одного лидера, а в документах, community, старых games и множестве людей.

Именно поэтому новая Quake становится всё более сложным identity problem.

## 63. Microsoft покупает ZeniMax { #p063 }

21 сентября 2020 Microsoft объявляет покупку ZeniMax Media за **$7.5 млрд cash**.

9 марта 2021 сделка закрывается.

Сразу нельзя совершать глупую ошибку:

```
MICROSOFT
ЗАПЛАТИЛА
$7.5B
ЗА id
```

Нет.

Она покупает весь ZeniMax portfolio: Bethesda Softworks, Bethesda Game Studios, id Software, Arkane, MachineGames, ZeniMax Online, Tango Gameworks, Alpha Dog, Roundhouse и огромный каталог IP.

Doom — только один кусок.

### Стратегия Microsoft

Xbox получает:

```
CONTENT
+
STUDIOS
+
IP
+
GAME PASS VALUE
+
PC / CONSOLE ECOSYSTEM
```

### Первоначальное сообщение — сохраняем studios

Не «теперь все становятся Microsoft Game Studio \#17», а Bethesda structure сохраняется.

Microsoft покупает функционирующую organization, а не просто IP archive.

### Для id immediate disruption минимален

Studio остаётся в Texas. Bethesda остаётся publishing layer. DOOM Eternal продолжает support.

Никто не переезжает в Redmond на следующий день.

### Game Pass становится важнейшим новым экономическим слоем

Будущая game теперь ценна не только:

```
СКОЛЬКО
КОПИЙ
ПРОДАЛИ?
```

Но:

```
ПРИВЛЕКАЕТ ЛИ
ОНА
В GAME PASS?

УДЕРЖИВАЕТ ЛИ
SUBSCRIBER?

УСИЛИВАЕТ ЛИ
XBOX ECOSYSTEM?
```

Это другая экономика.

### id теперь юридически first-party Xbox studio

Но возникает вопрос:

```
DOOM
ТЕПЕРЬ
XBOX EXCLUSIVE?
```

В 2021 Phil Spencer довольно прямо говорит, что цель acquisition в том числе — давать платформам с Game Pass отличные exclusive games, при сохранении existing contracts и legacy/community cases.

Starfield/Redfall покажут, что exclusivity была реальной strategy.

Мы отлично знаем, что Quake сделала с индустрией.

Гораздо труднее сказать, что Quake должна быть как современная game.

## 66. Doom: The Dark Ages и современная id Software { #p066 }

После Doom 2016 и Eternal id впервые за долгое время могла просто продолжить успешную формулу.

```
DOOM 2016
→ push-forward combat

DOOM Eternal
→ combat chess / mastery
```

Самый безопасный ход:

```
DOOM ETERNAL 2
+
новые demons
+
новые arenas
```

И id опять говорит: нет.

### Каждая Doom должна иметь свой глагол

Hugo Martin формулирует:

```
DOOM 2016
=
RUN AND GUN
```

```
DOOM ETERNAL
=
JUMP AND SHOOT
```

```
THE DARK AGES
=
STAND AND FIGHT
```

Eternal Slayer — fighter jet.

Dark Ages Slayer — iron tank.

Это не просто marketing phrase, а смена combat philosophy.

### Реакция на Eternal

Eternal довела decision density до почти character-action уровня.

Игрок одновременно следит за:

- movement;

- dash;

- Meat Hook;

- weapon switches;

- ammo;

- Flame Belch;

- grenades;

- weak points;

- cooldowns.

Для mastery — великолепно.

Но input complexity тоже огромна.

Dark Ages пытается часть глубины перенести:

```
ИЗ
КОЛИЧЕСТВА
КНОПОК

В
КАЧЕСТВО
РЕШЕНИЙ
```

### Stand and Fight — не значит «стой за щитом»

Shield имеет durability и перегружается.

Если просто держать block:

```
ты
играешь
неправильно
```

Нужно:

- strafe;

- parry;

- reposition;

- pressure;

- counterattack.

Eternal избегает damage через extreme vertical mobility.

Dark Ages контролирует damage через ground movement + active defense.

### Возвращается strafe-to-aim classic Doom feeling

Player снова сильнее читает поле как поток projectiles.

```
THREAT
↓
STRAFE
↓
PARRY
↓
COUNTER
```

Это почти first-person bullet hell.

### Shield Saw — центральная система

Один tool умеет:

```
BLOCK
PARRY
DEFLECT
THROW
STUN
BREAK ARMOR
SHIELD CHARGE
TRAVERSAL
PUZZLE INTERACTION
```

Очень modern id design:

```
ОДИН INPUT
↓
МНОГО
КОНТЕКСТНЫХ
РЕШЕНИЙ
```

### Parry становится ресурсной механикой

Successful parry не просто отменяет damage.

Она создаёт offensive opportunity и восстанавливает melee charges.

```
ENEMY ATTACK
↓
PARRY
↓
MELEE CHARGE
↓
MELEE
↓
AMMO
↓
GUNS
```

Defense встроена в attack loop.

### Melee заменяет chainsaw-function

Flail, Gauntlet, Mace.

Melee replenishes ammo.

То есть ресурс снова находится внутри aggression, а не в downtime.

### Но система действительно местами проще Eternal

Shield Saw очень универсален.

Есть риск:

```
ОДНА
ОЧЕНЬ
ХОРОШАЯ
МЕХАНИКА

НАЧИНАЕТ
ПОЖИРАТЬ
ОСТАЛЬНЫЕ
```

Weapons местами имеют менее жёсткие tactical identities, resource loop проще.

Для игрока, который особенно любит высокую decision density Eternal, Dark Ages может ощущаться как сознательный overcorrection.

### Glory Kills переделывают ради flow

Меньше ощущения отдельной synchronized animation sequence.

Player control важнее красивого lock-in.

Опять принцип:

```
ANIMATION
SERVES
GAMEPLAY
```

### Масштаб войны

Dark Ages хочет быть не «Slayer зашёл в комнату», а:

```
HELL ARMIES
VS
SENTINEL ARMIES
+
SLAYER
КАК
СУПЕРОРУЖИЕ
```

Больше enemies, шире battlefields.

Fantasy:

```
2016
→ dangerous combatant

Eternal
→ fighter jet

Dark Ages
→ siege machine
```

### Open zones

Не настоящий RPG-open-world.

Но большие spaces с objectives, optional fights, secrets и разным порядком движения.

Очень важный lesson после RAGE:

```
НЕ
WORLD
→ gameplay

А
GAMEPLAY
→ нужный размер world
```

### Atlan и Dragon

Giant mech и cybernetic dragon — чистый blockbuster spectacle.

Это сознательное расширение fantasy.

Но system depth у этих segments ниже основного Slayer combat.

Они скорее punctuation/intermission, чем второй полноценный combat game.

### Story становится cinematic

Dark Ages — полноценный prequel с kings, Sentinels, Maykrs и большими cutscenes.

На первый взгляд:

```
ОПЯТЬ
DOOM 4?
```

Нет, потому что hierarchy другая.

Старый Doom 4:

```
FICTION
→ GAME
```

Dark Ages:

```
PLAYER FANTASY
→ COMBAT SYSTEM
→ WORLD / STORY
```

Cinematics не проблема, пока они не становятся хозяином gameplay.

### id Tech 8

И вот здесь modern id снова делает hardcore engineering, но уже в правильной hierarchy.

Game требует:

- огромные levels;

- больше enemies;

- быстрое iteration content team;

- realtime lighting;

- 60 FPS.

Engine отвечает.

### Real-time ray-traced GI

Hardware RT становится baseline requirement на PC.

Но смысл не только «красивее reflections».

Realtime GI радикально улучшает production iteration:

```
изменил environment
↓
lighting
сразу соответствует
новой geometry
```

Не нужно бесконечно ждать bake.

Technology одновременно улучшает:

```
PLAYER OUTPUT
+
DEVELOPER WORKFLOW
```

### 60Hz всё ещё священно

Даже с RTGI, огромными fights и масштабом engine target остаётся 60Hz-class performance на target platforms.

Вот прямая institutionalized Carmack-value.

### Path tracing после релиза

В июне 2025 PC получает path tracing / advanced RTX features.

Billy Khan формулирует очень Carmack-like philosophy:

```
TECHNIQUE
имеет смысл
КОГДА
ОНА
SHIP'НУТА
В COMMERCIAL GAME
```

Не просто research demo.

### 15 мая 2025 — релиз

Xbox Series X\|S, PC, PS5, Game Pass.

Критически — хорошая, но немного более спорная reception, чем 2016/Eternal.

Главный раскол ровно ожидаемый:

```
Eternal mobility / density
VS
Dark Ages parry / ground control
```

### Revelations 2026

7 июля 2026 выходит большая expansion.

И здесь id делает максимально характерную вещь:

центральный Shield Saw сначала ломают и дают новый tool — Chain Spear.

Он умеет parry, dash, grapple и возвращает часть mobility Eternal.

Martin описывает это как:

```
MONSTER TRUCK
WITH A JET ENGINE
```

То есть id уже через год корректирует собственную successful thesis.

```
STAND AND FIGHT
↓
А ЧТО ЕСЛИ
ДОБАВИТЬ
БОЛЬШЕ MOBILITY?
```

### Ripatorium

Post-launch combat sandbox получает всё больше customization.

System должна жить дольше campaign.

Далёкая рифма с old modding philosophy.

### 2026 layoffs

Летом Microsoft проводит крупную волну сокращений.

id теряет значительное количество сотрудников, включая ветеранов.

Это реальный новый institutional stress-test.

Компания публично говорит:

- team всё ещё достаточно велика;

- size сопоставим примерно с Doom 2016-era;

- games и technology продолжатся;

- maker/flat culture хотят сохранять.

### id Tech не уходит на Unreal

Marty Stratton публично подтверждает:

```
ALL IN
ON id TECH
```

То есть own-engine identity всё ещё считается core competence.

### Что осталось от id 1993

Не ownership.

Не founders.

Не tiny team.

Не PC-only.

Не shareware.

Не external engine licensing.

Но осталось:

```
СИЛЬНОЕ
GAMEPLAY CORE

BUILD
ВАЖНЕЕ
ТЕОРИИ

PERFORMANCE
=
GAMEPLAY

PLAYER CONTROL
СВЯЩЕНЕН

OWN TECH
ДАЁТ
СВОБОДУ

НЕ БОЙСЯ
СЛОМАТЬ
СВОЮ
УСПЕШНУЮ
FORMULA
```

Поэтому современная id не та же компания буквально.

Но алгоритм принятия хороших решений местами удивительно узнаваем.
