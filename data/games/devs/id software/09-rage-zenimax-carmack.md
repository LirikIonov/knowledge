## 49. RAGE: первая новая большая IP id со времён Quake { #p049 }

RAGE — очень важный проект не потому, что он оказался следующей великой франшизой уровня Doom.

Его историческое значение в другом.

## 51. Продажа id Software компании ZeniMax в 2009 году { #p051 }

24 июня 2009 года ZeniMax Media объявляет о покупке id Software.

Очень важно сразу правильно расставить юридические уровни. Это не совсем:

```text
Bethesda купила id
```

Точнее:

```
ZeniMax Media
    │
    ├── Bethesda Softworks
    ├── Bethesda Game Studios
    └── id Software
```

Bethesda и id после сделки оказываются внутри одной материнской структуры. Bethesda становится издательской оболочкой будущих игр id, но сама покупка оформлена через ZeniMax.

Для id это конец огромной эпохи.

До 2009 года компания всё ещё оставалась независимой: могла сама выбирать издателя, сама решать, кому лицензировать движок, сама владеть IP и сама нести финансовый риск.

После сделки:

```
id Software
перестаёт быть
независимой компанией

↓

но остаётся
отдельной студией
```

И это важное различие.

### Кто владел id к моменту продажи

После ухода Romero, Hall и других первоначальная структура собственности уже давно изменилась. К середине 2000-х ядро владельцев составляли John Carmack, Adrian Carmack, Kevin Cloud, а позднее Todd Hollenshead и Tim Willits.

В 2004 году Activision уже пыталась купить id примерно за сумму порядка $100+ млн. Adrian Carmack, владевший очень крупной долей, склонялся к продаже, остальные владельцы — нет. Из этого вырос серьёзный внутренний конфликт и судебная история, после чего Adrian ушёл.

То есть миф:

```
id никогда
не хотела продаваться
```

неправильный. Предложения были давно. Спор был скорее:

```
КОГДА

КОМУ

НА КАКИХ
УСЛОВИЯХ
```

### Почему в 2009 продажа стала логичнее

Проблема не в том, что id вдруг закончились деньги. Проблема в том, что модель AAA-разработки радикально подорожала.

У компании одновременно были:

```
DOOM

QUAKE

WOLFENSTEIN

RAGE

id Tech
```

А сама id всё ещё оставалась одной сравнительно компактной студией.

RAGE и id Tech 5 требовали уже совсем другого масштаба: большие команды, консольные версии, огромный art pipeline, новые tools, долгие production cycles, отдельные группы под несколько проектов.

Независимая id могла это делать, но финансовый риск каждого цикла становился всё выше.

### Ещё одна проблема — внешний издатель

Когда id работает через Activision или EA, её IP остаются у id, но издательская компания естественно имеет собственные приоритеты. Для издателя id может быть очень важным партнёром, но всё равно партнёром среди многих.

ZeniMax предлагает другую конструкцию:

```
DEVELOPER

+

PUBLISHER

+

IP

+

CAPITAL

внутри
одной corporate group
```

И это резко уменьшает трение.

### Почему ZeniMax

Переговоры начинают развиваться после E3 2008. Todd Hollenshead общается с Robert Altman, дальше разговор постепенно превращается из обычных деловых контактов в возможное приобретение.

Для id ZeniMax интересна тем, что Bethesda уже доказала способность издавать и финансировать большие AAA-проекты, но при этом портфель компании не был забит прямыми конкурентами id в каждой FPS-нише.

Условно:

```
ACTIVISION
→ Call of Duty
  и другие shooters

EA
→ Battlefield
  и огромный portfolio

ZENIMAX / BETHESDA
→ Oblivion
  Fallout 3
  RPG / open-world expertise
```

id добавляет совсем другую силу.

### Цена сделки

Официальная цена покупки id не была публично названа. Поздние документы и финансирование ZeniMax дают ориентиры — в частности, фигурировало финансирование порядка $105 млн, связанное с acquisition, — но это не значит, что можно честно написать:

```
id была продана
ровно за $105 млн
```

Этого мы не знаем.

### Что обещала сделка

Главное — id могла расти. Публично говорилось о расширении примерно со ста сотрудников до порядка 130 и о возможности вести несколько крупных production lines.

Это важнейший shift:

```
СТАРАЯ id

одна team
→ один большой project
```

```
НОВАЯ id

несколько teams
→ несколько franchises
```

По крайней мере так выглядело намерение.

### Почему Carmack в целом был доволен

Carmack никогда особенно не любил business side. Contracts, boards, negotiations, publisher politics.

Его идеальный рабочий день:

```
КОД
```

Если ZeniMax забирает на себя часть legal/publishing/finance/business negotiations, для него это освобождает время на engineering.

### Старые контракты не исчезают в один день

После покупки существующие соглашения продолжают действовать:

- RAGE ещё связан с EA;

- Wolfenstein 2009 — с Activision.

То есть покупка не стирает договоры магически. Но будущий default теперь понятен:

```
id game

↓

Bethesda publishing
```

### Историческое значение

Продажа ZeniMax — конец **корпоративно независимой id Software**.

Но не конец студии.

Это очень важный recurring pattern всей истории:

```
одна версия id
умирает

↓

другая
остаётся
```

После 2009 id теряет суверенитет как компания, но получает шанс выжить как development institution.

## 52. Что реально изменилось после покупки ZeniMax { #p052 }

Снаружи первые годы могли выглядеть почти скучно.

Офис есть. Carmack есть. Willits есть. Hollenshead есть. RAGE делается. Логотип id тот же.

Но внутри фундамент уже другой.

### Управленческая структура

Todd Hollenshead до сделки — CEO независимой id. После покупки такой титул уже странно выглядит: над ним есть ZeniMax corporate hierarchy.

Поэтому структура меняется. Hollenshead становится President id Software, Carmack остаётся CTO.

Это символично:

```
раньше:

id
сама вершина
корпоративной пирамиды
```

```
после 2009:

id
часть
большей пирамиды
```

### Исчезает необходимость каждый раз искать издателя

До сделки:

```
сделали project

↓

кому отдаём publishing?

Activision?

EA?

кто даст условия?
```

После:

```
Bethesda
```

Для creative/engineering studio это огромная невидимая экономия внимания.

### Компания получает капитал для роста

Старая id долго гордилась компактностью. Но AAA 2010-х компактной уже не будет.

ZeniMax финансирует рост и multi-team ambitions. Примерно в этот период id переезжает из старого Mesquite в более крупный офис в Richardson.

Даже физически компания становится другой.

### Самое большое изменение — id Tech перестаёт быть внешним middleware-бизнесом

До acquisition id Tech 5 ещё активно представляли как будущего конкурента Unreal Engine.

В 2007–2008:

```
мы снова
серьёзно идём
в engine licensing
```

После покупки:

```
НЕ ПРОДАЁМ
НАРУЖУ

↓

оставляем
внутри
ZeniMax
```

Todd Hollenshead прямо объяснял это как сохранение competitive advantage внутри группы.

Теперь:

```
id Tech

не товар
для любой studio

↓

внутренняя
стратегическая
technology
```

### MachineGames показывает новую модель

ZeniMax покупает MachineGames в 2010.

И вот тут появляется новая цепочка:

```
id
создаёт engine

↓

MachineGames
использует engine

↓

Bethesda
издаёт game

↓

всё внутри
одного owner
```

id Tech не обязана приносить деньги продажей лицензии. Она может приносить ценность тем, что усиливает сестринские студии.

### Но Bethesda Game Studios не заставляют переходить на id Tech

Можно было сделать корпоративную глупость:

```
У НАС ЕСТЬ
КРУТОЙ ENGINE

↓

ТЕПЕРЬ
ВСЕ
НА НЁМ
```

Но Skyrim/Fallout-type RPG имеют совершенно другие requirements.

ZeniMax не превращает idTech в обязательный universal engine.

### IP становятся частью корпоративного portfolio

До 2009:

```
DOOM
=
asset id Software
```

После:

```
DOOM
=
asset ZeniMax group
```

Это значит, что franchise теоретически может жить и вне основной команды id.

Позже это станет нормой:

```
Wolfenstein
→ MachineGames
```

и remasters:

```
→ Nightdive
```

### Исчезает часть старой business-функции Hollenshead

Если ZeniMax/Bethesda теперь ведёт publishing, corporate finance, часть legal и portfolio strategy, то CEO-style business sovereign внутри id уже не так нужен, как раньше.

И это важно для понимания ухода Hollenshead в 2013: acquisition сама структурно уменьшила объём той власти, которую раньше концентрировал CEO независимой id.

### Деньги не решают design problems

ZeniMax может дать:

```
MONEY
TIME
STAFF
PUBLISHING
```

Но не может автоматически дать:

```
GOOD GAME
```

RAGE всё равно будет иметь identity issues. Doom 4 всё равно заблудится.

Покупка решает business continuity, но не creative direction.

## 53. RAGE 2011 — кризис идентичности id { #p053 }

RAGE нельзя честно называть плохой игрой.

Она получила нормальные/хорошие оценки, сильные отзывы на стрельбу, впечатляющую технологию и очень хороший production value.

Но исторически она гораздо важнее как симптом.

### Самое сильное в RAGE — стрельба

Когда id делает:

```
GUN
↓
ENEMY
↓
IMPACT
↓
REACTION
```

она всё ещё элита.

В RAGE прекрасно работают shotgun, assault weapons, ammo types, Wingstick, sentry bots, turrets, враги, которые карабкаются, уклоняются и хорошо реагируют на попадания.

Лучшие interior missions — Dead City, Shrouded bunker, Gearhead Vault, Mutant Bash TV — почти чистый концентрат сильных сторон id.

### А потом вокруг этого построили слишком много всего

RAGE хочет быть:

```
FPS
+
OPEN WORLD
+
DRIVING
+
RACING
+
NPC
+
QUESTS
+
CRAFTING
+
ECONOMY
```

И каждый кусок сам по себе может быть нормальным.

Проблема:

```
ПОЧЕМУ
ВСЁ ЭТО
ОДНА GAME?
```

### Пустошь выглядит открытой, но структурно не является полноценным open world

Типичный loop:

```
HUB
 ↓
CAR
 ↓
ROAD
 ↓
MISSION ENTRANCE
 ↓
LOAD
 ↓
LINEAR FPS LEVEL
 ↓
LOAD
 ↓
CAR
 ↓
HUB
```

Именно поэтому Willits потом сформулирует: не делайте open-world game без open-world technology.

id Tech 5 умела огромные уникально расписанные пространства.

Но:

```
UNIQUE VISUAL DATA
≠
SYSTEMIC OPEN WORLD
```

MegaTexture даёт картинке индивидуальность. Она не создаёт world streaming ecology, systemic activity, seamless interior/exterior и simulation.

### Машины — хороший feature, но они разбавляют лучшую часть

Driving не ужасная. Racing не ужасный.

Но вопрос:

```
ХОЧУ ЛИ Я
СЕЙЧАС
ЕЗДИТЬ

ИЛИ

ХОЧУ
ЕЩЁ
СТРЕЛЯТЬ?
```

И часто хочется второго.

То есть игра заставляет id вкладывать огромное количество ресурсов в activity, которая менее интересна, чем её core FPS.

### Hubs красивы, но функционально часто служат mission menus

Ты ходишь между NPC, получаешь quest, едешь в level, возвращаешься.

Мир не достигает плотности персонажей/систем Fallout или immersive sim.

Получается:

```
ДОРОГОЙ
КРАСИВЫЙ
INTERFACE
К МИССИЯМ
```

### Crafting тоже существует между мирами

Он не настолько глубокий, чтобы определять game.

Но достаточно заметный, чтобы добавлять cognitive/production overhead.

RAGE постоянно оказывается:

```
НЕ совсем
linear FPS

НЕ совсем
open world

НЕ RPG

НЕ racing game

НЕ immersive sim
```

### История и финал

Premise вполне нормальный: Apophis, Arks, Authority, post-apocalypse, buried survivors.

Но narrative не становится сильным glue.

И финал особенно известен своей резкостью. Игра фактически заканчивается там, где ожидаешь последнюю большую escalation.

Мы можем предполагать deadline/production pressure, но нельзя выдавать как доказанный факт:

```
ZeniMax
обрезала ending
```

Публичного надёжного подтверждения такой конкретной причины нет.

### Самый болезненный момент — PC launch

Именно id.

Компания, которая десятилетиями была символом PC graphics.

RAGE выходит на PC с driver issues, texture pop-in, blurry textures, crashes, tearing и очень ограниченными graphics options.

Carmack потом назвал запуск практически `clusterfuck`.

Это репутационно больнее обычного порта.

```
id
когда-то
ЗАСТАВЛЯЛА
людей покупать
новые видеокарты

↓

теперь
её новая
технологическая
витрина
плохо стартует
на PC
```

### PC больше не является единственным центром

Carmack прямо говорил, что consoles теперь имеют огромную коммерческую долю и становятся baseline для production.

PC получает сверху дополнительные преимущества, но game уже не строится исключительно вокруг high-end PC.

Для старого ядра фанатов это культурный удар.

### MegaTexture имеет очень заметный failure mode

Virtual texturing может дать фантастическую уникальность среды.

Но когда streaming не успевает:

```
PLAYER
БУКВАЛЬНО
ВИДИТ
ТЕХНОЛОГИЧЕСКИЙ
КОМПРОМИСС
```

Texture появляется у него перед глазами.

И вся marketing thesis технологии превращается в visible bug.

### Коммерчески RAGE не была катастрофой

Она продавалась. Была заметным релизом.

Но cultural impact не сравним:

```
DOOM
QUAKE
```

Не возникает новая огромная community identity. Не возникает жанрового сдвига.

### Почему нет RAGE 2 сразу

Если бы RAGE реально стала следующим мегастолпом:

```
2011 RAGE
↓
2013–14 RAGE 2
```

Но sequel приходит только в 2019 и уже с Avalanche.

Это много говорит о position franchise внутри id.

### Наследие RAGE всё-таки огромное

Она отрабатывает 60 FPS philosophy, multiplatform pipelines, enemy animation, gun feel, high-speed streaming и production scale.

Часть инженерных уроков напрямую полезна post-Carmack Doom.

### Главный вывод

RAGE — последний большой продукт старой модели:

```
CARMACK
придумывает
новую tech

↓

team
пытается
найти game
вокруг неё
```

В 1993 это даёт Doom.

В 2011 — уже не обязательно.

Графика зрелая. Жанры зрелые. Новый renderer больше не автоматически означает новую игру.

Вот кризис.

## 54. Doom 4 / «Call of Doom» { #p054 }

Doom 4 официально объявляют ещё в мае 2008.

Это важно: проект начинает жизнь ещё до завершения RAGE и до покупки ZeniMax.

И первоначальная идея логична:

```
DOOM II
↓
HELL ON EARTH
↓
современное
переосмысление
```

Проблема начинается с того, **как** команда решает представить Hell on Earth современной аудитории.

### Влияние рынка

Конец 2000-х.

Главный язык большого FPS:

```
Call of Duty
military spectacle
scripted sequences
cinematic camera
squads
radio chatter
global war
```

И старая версия Doom 4 начинает двигаться туда же.

Отсюда неофициальное прозвище:

### Call of Doom

Это не официальный title. Это критическая/внутренняя/медийная формулировка, потому что проект слишком сильно напоминал современный Call of Duty-style blockbuster.

### Что было в старом Doom 4

По утёкшим материалам и поздним рассказам:

- уничтоженная Земля;

- resistance;

- обычные soldiers;

- cinematic sequences;

- масштабная война;

- много human context;

- более реалистичный визуальный язык.

То есть:

```
НЕ
DOOM 3 horror

↓

А
WAR MOVIE
WITH DEMONS
```

### Ключевой design mistake

Команда фактически спрашивает:

```
КАК
ДОЛЖЕН
ВЫГЛЯДЕТЬ
СОВРЕМЕННЫЙ
УСПЕШНЫЙ FPS?
```

Вместо:

```
ЧТО
ДЕЛАЕТ
DOOM
DOOM'ОМ?
```

### Почему cinematic language конфликтует с Doom

Cinematic shooter часто требует:

```
ПОДОЖДИ
↓
ПОСМОТРИ
КАК NPC
ОТКРЫВАЕТ
ДВЕРЬ
↓
ИДИ
ЗА SQUAD
↓
ПОСЛУШАЙ
DIALOGUE
```

Classic Doom fantasy:

```
Я
И ЕСТЬ
СОБЫТИЕ
```

Hugo Martin потом формулирует разницу почти идеально:

```
BIG EVENTS
WITH A GUY
IN THEM
```

против:

```
ONE GUY
IN BIG EVENTS
```

### Важный нюанс: проект мог быть нормальной игрой

Marty Stratton позже говорил примерно:

```
МОГЛА
ПОЛУЧИТЬСЯ
ХОРОШАЯ
GAME

НО
НЕ ЧУВСТВОВАЛАСЬ
DOOM
```

Проблема — identity, а не обязательно craftsmanship.

### Перезапуски

Проект не отменяется одной красивой датой.

Скорее идёт серия внутренних изменений и перезапусков примерно в 2011–2013.

К концу 2012 / началу 2013 становится ясно:

```
СТАРАЯ
DIRECTION
НЕ РАБОТАЕТ
```

Весной 2013 Bethesda публично подтверждает, что ранняя версия Doom не достигала нужного качества/впечатления и команда полностью переориентирована.

### Что делает новая команда

Она начинает почти исследование собственной серии:

```
DOOM
DOOM II
DOOM 3

↓

ЧТО
У НИХ
ОБЩЕГО?
```

Не эстетика и не конкретные maps.

А gameplay DNA:

- speed;

- movement;

- guns;

- demons;

- projectiles;

- pickups;

- player power;

- aggression.

Отсюда родится:

```
PUSH-FORWARD
COMBAT
```

### Ирония ZeniMax

Corporate acquisition обычно представляют как убийцу creativity.

Но здесь финансовая подушка parent company позволяет:

```
ВЫКИНУТЬ
ГОДЫ
AAA WORK

↓

И ЕЩЁ
НЕСКОЛЬКО
ЛЕТ
ДЕЛАТЬ
НОВУЮ GAME
```

Независимая id могла не выдержать такой write-off.

ZeniMax paradoxically помогает творческому reboot.

## 55. John Carmack покидает id Software { #p055 }

22 ноября 2013 John Carmack окончательно покидает id Software.

Это конец огромной эпохи.

Последний из первоначальных четырёх founders больше не работает в компании.

Но сводить уход к:

```
Doom 4
поссорились

↓

Carmack ушёл
```

слишком примитивно.

### Главная причина — VR

Carmack всю карьеру движется к плохо определённой технической границе:

```
1990
PC scrolling
↓
1992
fast first-person 3D
↓
1996
true 3D / networking
↓
2000s
advanced rendering
↓
2012
VR
```

Когда consumer VR появляется в форме Oculus Rift, для него это практически снова 1991 год:

```
НИКТО
ЕЩЁ
НЕ ЗНАЕТ
ПРАВИЛА

↓

ОГРОМНОЕ
ПОЛЕ
ДЛЯ
ENGINEERING
```

### 2012 — Doom 3 BFG и Rift

Carmack начинает экспериментировать с HMD, показывает Doom 3 в Rift и становится одним из главных публичных evangelists Oculus.

Он хочет:

```
id games
+
VR
```

и пытается совместить работу в id с новой frontier.

### Но id уже не принадлежит Carmack

В 1996:

```
CARMACK
хочет
новое направление

↓

очень трудно
ему это запретить
```

В 2012:

```
CARMACK
хочет
стратегическое
VR partnership

↓

нужны
ZeniMax approvals
```

ZeniMax и Oculus не договариваются на условиях, которые позволили бы Carmack вести обе линии так, как он хочет.

### Август 2013 — Oculus CTO

7 августа Carmack становится CTO Oculus.

Сначала пытается формально оставаться и в id.

Но priorities уже очевидны.

VR становится для него главным.

### Ноябрь 2013 — полный уход

Совмещать две роли не получается.

Carmack полностью resigns from id.

Позднее между ZeniMax и Oculus/Facebook будет очень грязная судебная история, но для истории id важнее другое:

### Carmack больше не считает mature AAA id своей главной технической frontier.

### Почему это логично психологически

id к 2013:

- большая;

- корпоративная;

- production-heavy;

- multiplatform;

- делает sequel/reboot;

- имеет schedules;

- огромные teams.

Oculus:

- маленькая;

- новая;

- experimental;

- hardware + software;

- latency problems;

- фундаментальная research uncertainty.

То есть он в каком-то смысле ушёл **из современной id в то, чем старая id когда-то была**.

### Что id теряет

Не просто programmer.

Она теряет:

- technical north star;

- ultimate low-level authority;

- публичный инженерный символ;

- аппаратную связь с GPU/CPU индустрией;

- главного advocate open-source releases;

- историческую модель `новая tech → новая game`.

### Но одновременно это заставляет компанию взрослеть

Если после Carmack engine department умирает — значит id не была организацией.

Она была entourage одного человека.

Doom 2016 потом докажет обратное.

### Главный вывод

Carmack был практически необходим для **создания** id Software.

Но к 2013 компания уже выросла настолько, что может существовать **после него**.

И доказать это — один из самых важных сюжетов всей поздней id.

## 56. Todd Hollenshead покидает id Software { #p056 }

В 2013 уходит не только Carmack.

26 июня компанию покидает Todd Hollenshead после примерно 17 лет работы.

Это значит, что за несколько месяцев исчезают два столпа post-Romero id:

```
HOLLENSHEAD
=
business

CARMACK
=
technology
```

### Кто вообще Hollenshead

Он приходит в id в 1996. До этого работает в Arthur Andersen в accounting/tax/consulting. id была клиентом.

То есть он не ex-game designer. Он professional businessman. Сам себя когда-то иронично называл чем-то вроде «обязательный business guy».

И именно это компании после Quake desperately нужно.

### Его функция

После хаоса founders-era кто-то должен заниматься финансами, contracts, publishers, licensing, corporate issues, переговорами и публичным business representation.

Hollenshead позволяет Carmack не превращаться в CEO/bizdev человека.

После ухода Romero структура становится специализованнее:

```
Carmack
→ technology

Adrian / Cloud
→ art / ownership / production

Willits
→ design

Hollenshead
→ business
```

Это mature id.

### В 2004 Hollenshead становится совладельцем

Он уже не просто hired CEO. Он входит в ownership вместе с Willits и реально участвует в стратегической судьбе компании.

### QuakeCon

Для публики Hollenshead много лет ещё и лицо id на сцене. Он ведёт QuakeCon, разговаривает с press, объявляет проекты, объясняет business strategy.

### Продажа ZeniMax

Он один из центральных участников сделки 2009 года. После acquisition его титул естественно меняется:

```
CEO
→ President
```

потому что над студией теперь есть ZeniMax.

### Почему acquisition постепенно делает его старую функцию менее необходимой

До:

```
id
должна сама

искать publisher
вести legal
считать finance
делать corporate strategy
```

После:

```
ZeniMax / Bethesda
берёт огромный
кусок этого
```

То есть Hollenshead сам помогает построить конструкцию, внутри которой суверенный CEO id уже меньше нужен.

### Почему он ушёл

Официально — pursue other interests.

Нет надёжного основания писать:

```
его выгнали
из-за Doom 4
```

или:

```
из-за RAGE
```

Можно видеть организационный контекст, но не превращать inference в факт.

### Его не заменяют одним новым CEO

Вместо «Todd 2» функции распадаются:

- Bethesda/ZeniMax — business/publishing;

- Tim Willits — studio direction;

- Marty Stratton и project leads — production/game;

- engine leadership — technology.

То есть старая owner-executive модель id окончательно распадается.

### Историческое значение 2013

Если 1996 — конец original founder balance, то 2013 — конец **post-Romero mature independent-style power structure**.

В один год:

```
Hollenshead OUT

Carmack OUT
```

Именно поэтому Doom 2016 будет фактически второй founding moment компании.

## 57. Tim Willits и новая studio structure { #p057 }

Tim Willits — очень специфическая фигура.

Не founder. Не Carmack-level engineer. Не CEO.

Но именно поэтому его карьера почти идеально показывает, как id превращается из founder-band в institution.

### Начало — modder

Он играет в Doom, делает свои карты, его work замечает id, и его нанимают примерно во время Quake-era.

Это идеальный пример:

```
PLAYER
↓
MODDER
↓
PROFESSIONAL
id DESIGNER
```

### Он приходит в компанию в худший организационный момент

Quake production. Romero/Carmack conflict. Смена direction. Burnout. Уходы.

То есть Willits буквально учится game development внутри процесса, который одновременно является гениальным и дисфункциональным. Это будет влиять на его management philosophy позже.

### Важная осторожность: исторические заявления Willits

Willits позже делал несколько громких заявлений о собственном вкладе в early Quake/Doom design — например, про multiplayer-only maps или shareware episode ideas.

Romero, Hall, Carmack, McGee и другие ветераны некоторые из этих утверждений публично оспаривали.

Поэтому:

```
Willits
=
важнейший свидетель
```

но:

```
НЕ единственный
источник истины
про 1990-е
```

### После распада original team он остаётся

Многие ушли. Willits продолжает:

```
Quake
↓
Quake II
↓
Quake III
↓
Doom 3
↓
RAGE
↓
ZeniMax
↓
Doom 4 reset
↓
post-Carmack id
```

Он становится живой institutional memory.

### Doom 3

Он уже lead-level/design figure и один из ключевых creative leaders. То есть давно не просто mapper.

### 2004 — совладелец

Он вместе с Hollenshead входит в ownership. Это показывает, насколько вырос его статус.

### RAGE

Willits становится Creative Director / важнейшим design voice проекта.

Его описание происхождения RAGE очень характерно:

```
Carmack
делает MegaTexture
↓
team
смотрит
↓
«следуем
за магией»
↓
огромные spaces
↓
cars
↓
guns
↓
RAGE
```

Это чистая technology-first id.

### Но Willits уже думает как production manager

Его поздние принципы:

- знай реальное core team;

- используй сильные стороны конкретных людей;

- дай ownership features;

- закладывай failure в schedule;

- сделай game fun как можно раньше;

- постоянно playtest;

- core message должен быть простым;

- команда должна увидеть working prototype, а не только презентацию.

Это попытка сохранить маленькую id внутри большой id.

### Риск такой модели

Если каждый сильный человек идеально владеет своей feature:

```
CARS good
GUNS good
NPC good
CRAFTING good
```

это не гарантирует:

```
GAME good
```

RAGE показывает этот риск. Feature ownership требует ещё и очень сильного central editing/vision.

### К 2012–2013 Willits — Studio Director

После ухода Hollenshead и Carmack именно он остаётся самой публичной studio-level фигурой старой id.

Но он не становится новым Carmack или новым Hollenshead. Власть теперь реально распределена.

```
Willits
→ studio continuity

Stratton
→ project / production leadership

Martin
→ creative direction

Duffy / engine team
→ technology

Bethesda / ZeniMax
→ corporate business
```

### Главная роль Willits

Он мост:

```
ROMERO-era id
↓
CARMACK-era id
↓
ZENIMAX-era id
↓
POST-CARMACK DOOM id
```

Именно поэтому его уход 2019 года будет символическим концом Quake-era leadership — но уже не катастрофой для компании.
