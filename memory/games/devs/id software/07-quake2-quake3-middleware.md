## 36. Quake II: взрослая id после развала первой команды { #p036 }

Quake II очень полезно сравнивать с первым Quake не по графике и даже не по геймплею, а по тому, как две игры вообще появились на свет.

Quake:

\+

Именно поэтому Quake II — важнейший proof of concept новой id Software.

Компания доказала, что после ухода значительной части Doom/Quake-команды она не просто способна сделать ещё одну большую игру. Она способна сделать её организационно лучше.

При этом не надо романтизировать: финал Quake II всё равно был чудовищным crunch. Kevin Cloud вспоминал возвращения домой в пять утра, четыре часа сна и людей, спящих на раскладушках, диванах и полу. Разница не в отсутствии переработок — разница в том, что до этих переработок компания уже не потеряла год на выяснение, какую игру вообще делает.
Game Developer

После Quake id сознательно решила не повторять Quake

Это не ретроспективная интерпретация.

John Carmack в 1997 году писал практически прямым текстом:

Quake 1 с точки зрения игры был довольно messed up, и повторять это они не собираются.

Приоритет для нового проекта формулировался уже не только как:

сделать technology лучше

но и:

сделать
BETTER GAME

GitHub

Это важнейший сдвиг.

После Doom id могла думать:

выкристаллизуется вокруг неё

Quake доказал, что эта модель имеет чудовищную цену.

Поэтому Quake II начинается уже с уроком:

технологическое R&D может быть открытым, но текущей игре нужен фиксированный производственный вектор.

И впервые этот вектор задаёт не Carmack и не Romero

При этом Quake II вовсе не была просто «безопасным Quake»

Kevin Cloud специально говорил, что большинство новой команды имело мало профессионального game-design опыта, и они вполне могли сделать простой sequel.

Но не сделали.

Они были недовольны миром первого Quake как фундаментом нового проекта и фактически начали творческое направление заново. Для Cloud Quake II была одновременно созданием игры и построением новой команды.

И вот это самый точный итог.

id Tech не проиграла Unreal Engine потому, что John Carmack оказался хуже Tim Sweeney как инженер.

Она проиграла middleware-войну потому, что id Software и Epic Games в какой-то момент поняли слово engine совершенно по-разному.

Для id это прежде всего было:

выдающееся техническое ядро следующей игры.

Для Epic оно постепенно стало:

продуктом, сервисом, инструментарием и экосистемой, с помощью которых другие компании должны предсказуемо выпускать свои игры.

Первая философия дала id невероятную скорость технических революций.

Вторая дала Epic Unreal Engine.

И сам Carmack в итоге признал именно это: рынок можно было удержать, но для этого id пришлось бы перестать быть маленькой Carmack-driven лабораторией и построить огромную скучную, профессиональную middleware-машину.

Epic была готова это сделать. id — сознательно нет.
